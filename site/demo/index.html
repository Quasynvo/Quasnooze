The Fluid Motion Voice Engine visualizes conversation state. It is not phoneme-accurate lip sync. Real text uses Quasnooze’s existing API and permissions.

Voice is opt-in, local and visible.

On Windows, run npm run desktop. “Talk locally” asks the native companion to listen. This page never uses browser speech recognition, records audio, or silently enables wake listening. Use the native tray to verify or mute the microphone if disconnected.

“Stop voice” stops native speech/listening; it is not task cancellation. Speaking animation follows reported native state; its spectrum is decorative because native speech has no output-frequency feed. Use the labelled silent preview without a native host.

Quasnooze may store real conversations on your machine. Scripted previews are not AI responses, do not call tools, and are not saved by this page.
