# Fluid Motion — visual identity

**Signature:** three phase-offset interference ribbons around a dark glass core. Compact dual wave lines identify the core at small sizes. Motion communicates reported state; it never impersonates a permission or a progress measurement.

| Token | Value | Use |
|---|---|---|
| Canvas | `#080D19` | Dominant background |
| Glass | `#111D30` | Raised panel; use transparency sparingly |
| Text | `#EDF4FF` | Primary text |
| Secondary text | `#A8BBCE` | Explanatory copy |
| Ion cyan | `#6EE7F9` | Idle/listening accent |
| Orbital violet | `#A78BFA` | Processing accent |
| Plasma magenta | `#F0ABFC` | Spectral highlight |
| Signal amber | `#FFBF69` | Permission/interruption accent |
| Error crimson | `#FB7185` | Interrupted state, paired with text |

Use system sans-serif for interface text and system monospace for signal provenance. Keep glows local to the engine. Glass panels need a solid fallback and a visible border; do not put essential text over the brightest ribbon.

The five canonical motion states are idle, listening, thinking, speaking and error. Approval is a separate **permission condition** with an amber idle-like presentation and explicit Allow/Deny controls. It is not a sixth audio state and never grants permission itself.

See [../VISUALIZER.md](../VISUALIZER.md) for motion timing, signal semantics, accessibility, integration and validation. The organization Q is retained only as the Quasynvo organization mark.
