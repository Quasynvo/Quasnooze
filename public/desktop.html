Your Windows companion

On Windows 10/11 with Node.js 22+, open a terminal in your Pinch folder and run:

npm run desktop

The tray and floating widget stay active when this page closes. Enable local wake there after reviewing the microphone prompt. Requires an installed English Windows desktop speech recognizer and microphone permission.

No cloud speech fallback, hidden microphone, automatic administrator access, or promise of unrestricted desktop control.

For login startup, use the companion’s tray menu. It starts muted each time.

Choose the real local model

Names come from Ollama’s installed-model list. Choosing a menu number cannot save a model named “1”. Selection applies to subsequent turns and resets when Pinch restarts.
